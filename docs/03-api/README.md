# 03-api

## Escopo

Referência dos métodos de API consumidos nos templates wBuy. Cobre endpoints de categorias, configurações, cores e dados de produtos.

## Ordem Recomendada de Leitura

1. **visao-geral-api.md** — Panorama e tipos de chamadas (server-side vs client-side)
2. **categorygetall.md** — Todas as categorias
3. **categorygetlevel1.md** — Categorias nível 1 (raiz)
4. **categorygetlevel2.md** — Categorias nível 2
5. **categorygetlevel3.md** — Categorias nível 3
6. **configuracoes-config-tema-json.md** — Configurações do tema
7. **getcolors.md** — Cores da loja
8. **getlastorderuser.md** — Último pedido do usuário
9. **getvariations.md** — Variações (SKU) de produto
10. **productget.md** — Dados completos de produto

## Convenções Específicas

- **Tipo predominante:** reference
- **Dependências:** 01-introducao (contexto geral)
- **Nomenclatura:** Nomes de arquivo refletem nomes de funções API
