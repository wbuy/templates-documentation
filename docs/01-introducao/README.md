# Introdução

Bem-vindo à documentação de desenvolvimento de templates para a plataforma wBuy!
Aqui você encontrará tudo o que precisa para criar temas visuais personalizados para lojas virtuais usando a stack de templates wBuy, que combina HTML, CSS, JavaScript e a engine de templates Twig.

## O que é a plataforma wBuy?

A wBuy é uma plataforma de ecommerce que permite que lojistas criem e personalizem suas lojas virtuais. Através da stack de templates wBuy, os desenvolvedores podem criar temas visuais únicos e interativos, acessando dados da loja em tempo real e utilizando uma variedade de recursos para melhorar a experiência do usuário.
